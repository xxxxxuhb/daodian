## 1. 第一次打开

打开后是一个窗口，底部三个入口：**待办 / 计划 / 已完成**，右上角是搜索和时间。

- **关窗口不会退出**。它会缩到右下角的托盘里，继续给你提醒。想真正退出，右键托盘图标选「退出」。
- **窗口有三档**：迷你（380 宽）、标准（900 宽）、宽屏。每档各自记住自己的大小和位置。
- **换主题**：左下角的月亮 / 太阳图标，青瓷（浅色）和夜航（深色）两套，记在本机。

第一次用，建议先做一件事：建一条 5 分钟后到点的待办，看看提醒长什么样。这样你会立刻知道它值不值得留下。

## 2. 待办

一件临时的事，只有一个时间点。

### 新建

顶部一行输入名字，右边的时间点选一个：

| 选项 | 含义 |
| --- | --- |
| 不设时间 | 只是记下来，不提醒 |
| 今天 15:00 | 今天下午三点提醒 |
| 明天 09:00 | 明天上午九点提醒 |
| 自选 | 自己挑日期和时间 |

回车或点「+」就建好了。点开任意一条可以改标题、时间、重要程度、备注。

### 重复

编辑里可以把一条设成重复：

- **每天**
- **每周**（可选星期几）
- **每个工作日**（自动跳过周末）
- **每月最后一天**
- **每 N 天**

还可以设置：

- **跳过周末**：节假日和调休日在「设置 → 重复与工作日」里补，补了就按你的日历算；
- **截止日期**：重复到某天为止，之后不再生成；
- **跳过这一次**：只推掉当下这一轮，不影响以后。

### 完成、跳过、延期

- **完成**：勾上，进「已完成」栏，不再提醒。
- **跳过这一次**：重复条目专用，这一轮不要了，下一轮照常。
- **延期**：在到点的提醒卡片上，把珠子往右拖到 10 分钟 / 30 分钟 / 1 小时。

### 分组

列表按时间分栏：**今天 / 以后 / 逾期 / 已完成**。逾期和快到点的条目左边有一条颜色，扫一眼就知道哪条要处理。

## 3. 计划

一件要分阶段推进的事，每个阶段一个时间点。

### 新建

点「+」进入编辑：

1. 填计划名，比如「1.2 版本」；
2. 逐个加阶段，比如「提测 / 发布 / 观察」，每个阶段给一个时间；
3. 最多 20 个阶段。

保存后，卡片上是一条阶段进度线，**下一个到点的阶段会单独标出来**，其余灰色。

### 两种视图

- **卡片**：一份计划一张卡，看阶段进度。
- **时间轴**：把几份计划排在同一条日历线上，谁先到点一眼看出来。窄窗口下时间轴会自动换一种排法，不挤。

顶部可以切「本周 / 本月」，也可以只显示重要的事。

### 模板

固定节奏存成模板：编辑计划时选「存为模板」，下次新建时一键铺开。常用的模板会出现在输入框下面。

内置了几个常用的，也可以自己改名、删除、设成快捷模板。

## 4. 备忘录

一篇能挂时间点的笔记。会议记录、需求草稿、排障过程都适合。

### 列表

- 顶部搜索，标题和正文都能搜到；
- 筛选：全部 / 最近 / 有到点 / 归档；
- 卡片可以置顶、归档、删除，右上角 ⋯ 里还有导出。

### 编辑

- 富文本：标题、正文、列表、引用、代码块、分割线；
- **表格**：插入后可以增删行列、设表头、拖列宽；
- **图片**：截图直接粘贴、拖进来，或点工具栏选文件；大图自动生成缩略图，点击看原图；
- **任务清单**：能勾选；
- **链接**：选中文字加链接；
- 输入 / 弹出块菜单；输入 # 、- 、[] 这类前缀会自动变成对应格式；
- 会自动保存，切走或关窗口前也会存。

### 到点

笔记可以设一个时间点，到点提醒你「该看这篇了」。规则和待办一样：只响一次、免打扰时段顺延、每小时最多 3 条。

### 引用

在笔记里输入 @，可以引用一条待办、一份计划或某个阶段，点击能跳过去。

### 导出

⋯ 菜单里可以导出 Markdown 或 HTML。

### 容量

单篇正文上限 2MB，单张图片 10MB，一篇最多 200 张图。超了会提示。

## 5. 提醒

到点会弹**系统通知**，窗口里同时出现一张「珠子落盘」卡片。

### 规则

提醒是为了不漏，不是为了多响。

- **同一条只响一次**，不会反复骚扰；
- **22:00–08:00 免打扰**：到点照算，但不弹；第二天 8 点合并成一条；
- **每小时最多 3 条**，超出的先攒着，整点后合并；
- **同一批合并成一条**：「3 件到点 · 提测评审、交周报 等 3 件」；
- **发不出去会退避**：同一条最多试 3 次，之后只记账，不再刷通知中心。

### 收到提醒时

卡片上有标题、时间、备注，还有三种处理方式：

- 点「完成」→ 这条结束；
- 点「打开」→ 进主窗口处理；
- **把珠子往右拖** → 落在 10 分钟 / 30 分钟 / 1 小时的刻度上，就延后到那时。

### 通知不响怎么办

先看第 15 节「到点了但没有通知」。

## 6. 桌面珠子

桌面上会有一颗小珠子，就是标志上那颗。它替你盯着时间。

### 它会变

| 状态 | 表现 |
| --- | --- |
| 发呆 | 平缓呼吸，偶尔歪头 |
| 快到点 | 变琥珀色，外圈走一圈 |
| 到点 | 外圈炸开，摊成一张小卡 |
| 深夜 | 变灰闭眼，不再打扰 |

### 怎么摸它

- **拖**：拖到哪都行，松手吸附到屏幕边，位置记住；
- **按住**：会捏扁，松手弹回；
- **双击**：打开主窗口；
- **右键**：暂停 1 小时，或打开主窗口；
- **到点时**：小卡上直接「完成」或「推后 10 / 30 / 60 分钟」。

不想看到它：设置 → 桌面珠子 → 关掉。

## 7. 快速记录

任何时候按 **Alt + Space**，弹出一个只有一行的小窗。

写完回车，这条就进待办了，不用切回主窗口。Esc 取消。

快捷键可以在「设置 → 快速记录」里改。如果组合被别的软件占用，界面会提示注册失败，换一个即可。

## 8. 日历

在「设置 → 日历」里选一个本地的 .ics 文件（Outlook、飞书、Google 日历都能导出）。

导入后，会议和你的待办、阶段会排在同一条时间轴上，一眼看出哪几个会撞车。

日历只是只读参考，不会改动你的日历原文件。会议改了，重新导入一次即可。

---

## 9. 周报

在待办页底部有「复制周报」。

它会按本周范围自动拼出三段：

- **概览**：完成多少、逾期多少、几个计划有进展；
- **待办**：本周完成的条目；
- **计划推进**：本周有进展的阶段。

点一下就复制成纯文本，贴到聊天框里就能发。模板可以在「设置 → 周报」里改，也能调成上一周。

## 10. 推送到群里

如果你想把到点同步到飞书或企业微信的群：

1. 在群里加一个机器人，拿到 Webhook 地址；
2. 打开「设置 → 飞书与企业微信」，把地址粘进去；
3. 点「测试」，群里会收到一条测试消息。

之后每次到点，除了本机通知，还会往群里发一条。不想发了，把开关关掉即可。

> Webhook 地址等同密码，别截图外发。

## 11. 一句话变成计划

如果你有 DeepSeek 的 Key，可以少敲很多字。

### 开起来

设置 → DeepSeek，填入 Base URL 和 API Key，点「测试」。Key 会加密存在本机。

### 怎么用

- **待办**里写「明天下午三点交周报」→ 它自己解析出时间和标题；
- **计划**里写「1.2 版本要提测、发布、观察」→ 它自己拆成三个阶段，并给时间建议。

生成的阶段可以先改再存，不会直接落库。

## 12. 设置一览

设置是一个抽屉，十一组：

| 组 | 管什么 |
| --- | --- |
| 外观与窗口 | 主题、窗口三档的尺寸与位置 |
| 重复与工作日 | 默认跳过周末、节假日、调休日 |
| 工作时间 | 上下班时间，供排期和 AI 参考 |
| 周报 | 模板、统计哪一周 |
| 日历 | .ics 文件路径、自动刷新 |
| 飞书与企业微信 | 两个 Webhook 地址与测试 |
| 桌面珠子 | 开关、位置、隐藏 |
| 快速记录 | 快捷键开关与组合 |
| DeepSeek | Base URL、API Key、模型 |
| 数据备份与恢复 | 每日快照列表、回滚 |
| 数据导出 | 导出成 Excel |

## 13. 数据与备份

### 数据在哪

开发版在 %APPDATA%\com.daodian.app\，安装版优先写在程序旁边。目录里主要是：

| 文件 | 内容 |
| --- | --- |
| store.json | 待办与计划 |
| templates.json | 计划模板 |
| settings.json | 全部设置 |
| deepseek-key.dpapi | 加密后的 Key |
| backups/ | 每日快照 |
| logs/ | 运行日志 |

### 自动备份

每天会自动存一份快照在 backups 里，按日期命名。

**恢复**：设置 → 数据备份与恢复 → 选一个日期 → 恢复。恢复前会先把当前数据也备份一次，所以点错了还能退回来。

### 导出

设置 → 数据导出，会把待办和计划导出成 Excel，方便给别人看或者做统计。

### 换机器

把整个数据目录拷过去即可。想更稳妥：先导出 Excel 留一份，再拷目录。

## 15. 常见问题

### 托盘图标找不到

Windows 11 默认把新图标折叠到「隐藏的图标」里。点任务栏右下角的 ^ 找找，找到后拖到任务栏上就固定了。

也可以在「设置 → 个性化 → 任务栏 → 其他系统托盘图标」里把「到点」打开。

### 到点了但没有通知

按顺序检查：

1. **Windows 通知设置**里，「到点」是不是被关掉了；
2. **专注助手 / 勿扰**是不是开着；
3. **是不是免打扰时段**（22:00–08:00 会攒到第二天 8 点）；
4. **是不是开发态直接跑的 exe**。系统需要一个带应用标识的开始菜单快捷方式才认这个应用，直接跑编译产物时可能被丢弃。用安装包装一次通常就好了。

### 关了窗口找不回来

窗口没退出，在托盘里。左键单击托盘图标，或者双击桌面珠子。

### 启动就报错

先看 logs\daodian.log 最后几行的 ERROR。日志在程序旁边；程序目录不可写时在 %LOCALAPPDATA%\daodian\logs。

常见原因：数据目录被安全软件限制。日志里会写清楚卡在哪一步（取数据目录 / 打开 store.json / 打开主窗口 / 初始化托盘）。

### 数据会不会被上传

不会。所有记录都在本机，程序没有账号体系，也不联网（除非你自己开了 DeepSeek 或群通知）。

### 能不能多台设备同步

目前不支持。设计上就是单机、本地、可备份。

### 提醒太多 / 太少

免打扰时段和每小时上限目前是固定的（22:00–08:00、每小时 3 条），还不能在界面里改。
