# 到点：给每一件事一个时间点

临时的事用待办，分阶段的用计划。到了那个时刻，提醒一次。

多数待办软件留的是截止日期。截止日期是一段范围：这周五之前做完就行。手上的事常常不是范围，是一个点。下午三点交周报。周四下午发版评审。发布之后再观察三天。时间走到那里，就该响一声。

到点是一个 Windows 桌面应用，只记这些点。

## 两类事情

临时的事进待办。顶部一行写完，时间四选一：不设、今天下午三点、明天早上九点，或者自己选。列表分成今天、以后、逾期、已完成。快到点和已经过了的，行首有一条颜色。

重复可以按天、按周、按工作日，也可以每月最后一天，或每隔几天一次。周末能跳过，节假日和调休日在设置里补。某一轮不做，就跳过这一次，后面的节奏还在。

分阶段的事进计划。一份计划拆成最多二十个阶段，每个阶段自己的时间点。卡片上是一条进度，下一个到点的阶段单独标出来。切到时间轴，几份计划排在同一条日历上，哪天叠在一起，一眼能看见。

提测、发布、观察这种走了很多次的节奏，存成模板。常用的会出现在输入框下面，点一下就铺开。

## 桌面上的那颗珠

标志是一只表盘。指针走到两点方向，尽头一颗实心的珠，那就是「到点」。

这颗珠放在桌面右下角。主窗口关了，它还在。平时很小，会自己动一动：歪一下头，打个哈欠，转转触角。快到点时表情会变。到点了，它在桌面上摊开一张小卡片，可以直接完成，或者把时间往后推。晚上十点到早上八点，它睡觉。

鼠标移过去，它跳两下。拖到屏幕边缘会吸住。按住会捏扁，松手弹回来。双击打开主窗口。右键可以让它安静一个小时。

窗口缩进托盘之后，时间还在算。到点弹的是系统通知。

## 少响几次

提醒是为了不漏，不是为了多响。

同一条只响一次。阶段里已经错过的，记一笔，不逐条补发。夜里十点到早上八点，到点照样算，但不弹，第二天八点合并成一条。一个小时最多三条，多出来的先攒着，一起说「3 件到点」，而不是连着弹三下。通知发不出去会退避，同一条最多试三次，然后只记账。

稍后不用在通知里找按钮。窗口里那张卡片上，把珠子往右拖，落在十分钟、三十分钟或一小时的刻度上，就延到那里。

## 留在这台电脑上

没有账号。待办、计划、模板和设置都是本机的 JSON，放在用户目录里。工作时间里按天留一份快照，设置里可以查看，也可以一键恢复。要交给别人，就导出成 Excel。

旁边可以接几样东西，都不是必须的。

任何时候按 `Alt + Space`，弹出一行。写完回车，就进待办，不用把主窗口找出来。这个快捷键可以改。

选一个本地日历文件，Outlook、飞书、Google 导出的 `.ics` 都行。会议和待办、阶段排在同一条时间轴上，能看出哪几场撞在一起。

飞书或企业微信配一个机器人，到点除了本机通知，还能把这一条发到群里。

填了 DeepSeek 的 Key 之后，待办里写「明天下午三点交周报」，它解析出时间；计划里写「这个版本要提测、发布、观察」，它拆成阶段，并给一个时间建议。Key 用 Windows 的 DPAPI 加密，只在这台电脑上解得开。不填的话，全部用手写。

一周结束时，按本周完成的待办、还在推进的计划，以及接下来七天，套一段可以自己改的模板，复制成纯文本。那就是一份周报草稿。

窗口有小、中、大三档。下次打开用你选的那一档，也记住各自的位置。颜色有两套：青瓷、夜航。可以开机启动，启动后先藏进托盘。

## 它停在哪里

到点不做协作，也不做多端同步。下一件什么时候到，看这台电脑就够了。

目前在 Windows 上使用。源码在 [github.com/xxxxxuhb/daodian](https://github.com/xxxxxuhb/daodian)。

本地跑起来：

```bash
pnpm install
pnpm tauri dev
```

安装包：

```bash
pnpm tauri build
```
