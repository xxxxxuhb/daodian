要加的字段 · pet_input.rs

PetKeyEvent {
  id:    1287,
  vk:    0x08,        // 物理键码
  label: "Bksp",      // 关掉键名时 null
  edge:  "down",      // 新增 up
  mods:  0b0011,      // Ctrl | Shift
  t:     18432,       // 相对毫秒
}
// 修饰键不落字块，改驱动蓄力

验收

  • 形象：与 pet-sheet.png 逐像素一致，只多字块、激光、波
  • 因果：连打 20s 必出时滞；1.5s 12 键必出冲击波
  • 心率：10 键/秒呼吸 ≈1.5s；停手 4s 回到 3.6s
  • 热区：指针离字块 >40px 时，场景对桌面完全穿透
  • 性能：20 键/秒 ≥55fps；无输入 0 帧
