# 珠子 · 输入互动 v2

> 现在的三种大招（冲击波、时滞、松劲）是在字块堆到 8 块之后**掷骰子**出来的，和你此刻怎么敲没有关系。
> v2 只做两件事：让已有的特效**有理由**，再加五个**只用现有像素**的互动。

图：[../out/pet/interact.png](../out/pet/interact.png) · 原型：[interact.html](interact.html)　·　旧方案：[方案.md](方案.md)（只加打掉字符）

---

## 结论

1. **调度先改**：三个特殊状态从「随机」换成「由输入节奏触发」，规则可读、可预期、可调参。
2. **键位人格**：`Bksp / Enter / Esc / Space / Tab / 方向键` 各有一个小动作，其余键仍是普通字块。
3. **心率**：打字速度驱动珠体呼吸、天线余晖、发射间隔——不加一个像素，加的是「活着」。
4. **收工**：停手后残余字块被吸回，珠子鼓一下，报一句这次敲了多少下。
5. **蓄力穿透**：按住 Ctrl/Shift 蓄力，松手一发穿三块。
6. **手动参与**：指针靠近字块时临时开一小块热区，可以自己点掉、也可以拖去喂珠子。

不改：珠子的形状、尺寸、颜色、环、天线、眼睛、位置，以及拖拽 / 捏扁 / 双击 / 右键 / 滚轮 / 到点卡片。不新增瞳孔、嘴、手脚、键盘。

---

## 一、调度：把"抽奖"换成"读节奏"

统计量都来自事件流（内存里滚动窗口，不落盘）：

| 量 | 定义 |
| --- | --- |
| `rate` | 最近 3 秒的键/秒 |
| `steady` | 最近 20 秒键间隔的标准差（越小越稳） |
| `burst` | 最近 1.5 秒的按键数 |
| `linger` | 距最后一次按键的毫秒数 |
| `stock` | 场上块数 = 队列 + 飞行中 |

状态机（同一时刻只跑一种特殊；普通射击除此之外一直在跑）：

| 状态 | 判据 | 反应 | 冷却 |
| --- | --- | --- | --- |
| 打字 | `rate ≤ 4` | 一发一块 | — |
| 连发 | `rate ≥ 4` 持续 12s | 发射间隔 150 → 110ms | — |
| 爆发 | `burst ≥ 12` | `boom` 冲击波 | 90s |
| 心流 | 连发持续 40s 且 `steady` 低 | `still` 时滞 | 120s |
| 泄气 | 已敲 ≥ 20 键，`linger ≥ 6s`，`stock ≥ 4` | `slack` 松劲 | 60s |
| 收工 | `linger ≥ 6s`，`stock` 为 1–3 | 吸收 + 鼓一下 | 12s |

规则：

- 任意两个特殊之间至少隔 20 秒；同一种 90 秒内不重复。
- 触发的先决条件和现在一样：窗口可见、没悬停、没开卡片/菜单、不是深夜睡着、`system_allows_motion` 为真。
- 判据互斥（爆发 > 心流 > 泄气 > 收工），不需要随机数；随机只保留在「选哪一块先打」这种无关紧要的地方。

**为什么值得改。** 用户能观察到的因果才叫回应；观察不到的随机只是动画。改完之后：「刚才手一快它就炸了一下」「我停下来的瞬间它塌了」——这两种记忆比多三种特效值钱。

## 二、键位人格

只对**有名字的键**生效；其余键走普通字块。同类动作 160ms 内合并。

| 键 | 珠子 | 场上 | 时长 |
| --- | --- | --- | --- |
| `Bksp` `Del` | 尖端亮一下 | 最近一块**不炸**，沿弧线缩回尖端被吃掉 | 320ms |
| `Enter` | 下压 `scale(1.2,.76)` 再回弹，环 25→23→25 | 全部字块 ±2px 震一下 | 400ms |
| `Esc` | 整体缩到 `.86` 回弹，眼睛一瞬 `1.2×` | 无 | 280ms |
| `Space` | 天线朝左压 6° | 三条提速线，字块 `vx −= 180`，0.6s 淡出 | 600ms |
| `Tab` | 复用 hop 跳一下 | 最老的一块右移 12px（让路） | 500ms |
| `↑ ↓ ← →` | 眼睛朝该方向偏 3px | 无 | 400ms |

边界：

- `Bksp` 只吃「已落定」的块（`now - born ≥ 140ms`），否则视为普通键，避免连删时空转。
- `Space` 只推不炸，被推走的块算「漏打」，不影响命中率。
- 全部动作走**已有的** `playAction` 通道，新增的只是 CSS 关键帧；`peek / startled` 这类随机小动作优先级更低，会被打断。

## 三、心率

用 `rate` 映射三个量，全部是 CSS 变量 + 一个常数：

| rate（键/秒） | 呼吸周期 | 幅度 | 尖端余晖 | 发射间隔 |
| --- | --- | --- | --- | --- |
| 0 | 3.6s | 1.02 | 4px | 150ms |
| 4 | 2.7s | 1.03 | 6px | 140ms |
| 7 | 2.0s | 1.04 | 8px | 125ms |
| 10+ | 1.5s | 1.05 | 9px | 110ms |

- 只改 `--pulse-dur` / `--pulse-amp` / `--tip-glow`，`pet-breathe` 已经在 `transform-origin: 48px 52px` 上，直接吃变量。
- 停手后 4 秒**线性**回落，不做跳变；深夜睡着时无视心率，固定慢呼吸。
- 环不动：环是「到点进度」，不参与心率，避免两个语义打架。

---

## 四、收工

停手满 6 秒（`IDLE_HOME` 7 秒之前）：

| 时刻 | 动作 |
| --- | --- |
| 0ms | 锁定场上 1–3 块 |
| 0–500ms | 每块错峰 60ms，沿贝塞尔吸回尖端，缩放 .9 → .2，无爆点 |
| 300ms | 珠体 `scale(1.06)` 起 |
| 500ms | 回落；环外扩 25 → 38，0.6s 淡出 |
| 1100ms | 结束。把「本次 12 分钟 · 640 下」写进内存，悬停时显示 4s |

只记两个数：时长、次数。不记键名、不记顺序、不跨会话。切窗口、暂停、隐藏、锁屏即清零。

## 五、蓄力与穿透

需要 Rust 补 `keyup`（现在只有按下沿，见 `pet_input.rs`）。

- 按住 `Ctrl` 或 `Shift` ≥ 240ms 进入蓄力：环 25 → 21（180ms ease-out），颜色**加深**到 `#0B4E62`；尖端 r 3.5 → 4.6、发热成琥珀并加光环；眼睛朝最老的字块。
- 蓄力期间新字块下落速度 ×0.7，发射间隔 ×1.6（给"瞄准"留时间）。
- 松开：粗激光（辉光 5px / 芯 1.4px），**沿途命中最多 3 块**，命中点依次爆，280ms。
- 上限 2.4s 自动满蓄；`Esc` 取消；蓄力时**不落修饰键字块**（现在按 Ctrl 会掉一块 "Ctrl"，这就是要改掉的那点怪）。
- 单独按修饰键不产生任何字块。

## 六、手动参与

难点不是画，是**别抢桌面点击**。现在的 `effect` 模式把 (0,40)–(300,300) 整块并进了窗口区域，打字时那块透明区会吃掉桌面点击（`pet.rs` 只调了 `SetWindowRgn`，没做穿透）——顺手在这里修掉。

做法：

1. `pet_input` 的 30ms 循环里加 `GetCursorPos`，当前场上字块的位置由前端每 100ms 上报（屏幕坐标）。
2. Rust 只保留与指针距离 < 18px 的**最多 2 块**，生成 40×40 热区矩形，并进 `SetWindowRgn`；指针离开即撤回。
3. 没靠近时窗口保持原来的珠子区域，其余完全穿透。

交互：

- **点掉**：命中热区 → 该块直接墨爆（没有激光），珠体 `scale(.96)` 60ms + 眼睛看过去。
- **喂食**：按住字块拖到珠子上松手 → 吃掉，珠体 1.05 回弹，`feed++`；`feed ≥ 5` 打一个饱嗝（轻量 `slack` 0.9s）并清零。
- 单击珠子本身仍是原逻辑（打开 / 卡片），只有「拖拽中」才进入喂食。
- 深夜睡着时热区不开放。

## 七、可选彩蛋（P2，先不做）

`Ctrl+S` 落盘（珠子沉一下 + 一圈涟漪）、`Ctrl+Z` 字块倒放、`Ctrl+A` 全吸。都需要修饰键状态和节流，且这些键在别的软件里很常见，容易变成噪音。等前六条稳了再说。

## 八、明确不做

- **不加手脚、嘴、腮红、新瞳孔**，不画键盘。形象是产品标志，动效只能是它的姿态。
- **不读文本、不读输入法、不截屏**。只有键名（可关）、次数、时间间隔。
- **不做引力反转 / 镜面 / 连锁**：视觉噪音大，和「安静陪伴」冲突，且需要新的几何语义。
- **不做常驻计数面板**：唯一的数字出现在收工那一句，4 秒后消失。

## 十、隐私（沿用并加一条）

- 只读当前按下的物理键名；不读文本、输入法候选、剪贴板、窗口标题。
- 字块、次数、间隔全部只活在组件内存里；窗口隐藏 / 暂停 / 锁屏即清空。
- 新增的只有「本次敲了多少下、敲了多久」，且只在悬停时显示 4 秒，不写日志、不落盘、不联网。
- `show_key_names` 关闭后，键位人格只影响珠子的姿态，DOM 里不出现键名。

## 十一、验收

1. 形象：任何状态下珠子与 `design/pet/out/pet-sheet.png` 逐像素一致；新增的只有字块、激光、波、热区（不可见）。
2. 因果：连打 20 秒必出 `still`；1.5 秒 12 键必出 `boom`；停手 6 秒且剩 4 块必出 `slack`；三种在 90 秒内不重复。
3. 心率：10 键/秒时呼吸 ≈ 1.5s；停手 4 秒后回到 3.6s，无跳变。
4. 键位：`Bksp` 只吃最近一块且不爆；`Enter` 时环收紧再回弹；连按 20 次不累积位移。
5. 蓄力：按住 240ms 出现琥珀环；松手最多打掉 3 块；`Esc` 取消后无残留。
6. 热区：指针离字块 > 40px 时，场景区域对桌面完全穿透（用截图工具在珠子上方拖动验证）；靠近后 100ms 内可点中。
7. 性能：20 键/秒时帧率不低于 55fps；无输入时 0 帧、CPU ≈ 0。
8. 多 DPI：100% / 125% / 150% 下热区与字块位置不偏移。
