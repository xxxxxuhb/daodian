# 桌面珠子 · 只加“打掉字符”

> 形象一像素不改。只多三样：从左侧掉下的字块、天线尖端的激光、两颗白点眼睛的平移。

## 结论

现在的桌面珠子就是品牌标志上那颗：92px、25px 的环、一根竖天线、两颗白点眼睛。**形状、尺寸、颜色、环、天线、位置、拖拽/捏扁/双击/右键/到点卡片全部保持原样。**

这次只加一个动作：

1. 你每敲一个键，按键名变成一块小字牌，从桌面左侧落下。
2. 珠子先“看”过去：两颗白点眼睛朝字牌平移，最多 3px；不新增瞳孔。
3. 天线不动，从原来的天线尖端发一条细激光，打到字牌。
4. 字牌炸成几颗小点；激光淡出。
5. 没有字在飞时，眼睛可以跟鼠标指针；7 秒无输入回正。

不画键盘，不画鼠标，不换猫，不加嘴/腮红/新瞳孔。

| 项 | 保持 |
| --- | --- |
| 尺寸 | 珠子 92px，外边距 96px 的点击区 |
| 结构 | 圆珠 r16、外环 r25、竖天线、尖端 r3.5 |
| 颜色 | 珠身 #15637B、眼睛白、环青、到点琥珀 |
| 位置 | 右下角，保存的仍是珠子左上角；旧位置升级后不跳 |
| 交互 | 拖拽吸附、按住捏扁、双击打开、右键菜单、滚轮推后 |
| 到点 | 外环走琥珀色、珠子摊成提醒卡，原逻辑不变 |
| 深夜 | 闭眼、变灰，不新增状态 |

## 只加的三样

### 1. 字块

- 按键名 → 22px 小牌（多字符如 Enter / Space 变宽到 44px）。
- 从场景左侧随机位置落下：x 26–110、y 54–124，带轻微旋转和向右漂移。
- 字块最多 14 块；打不完的自然落到下方消失。
- 关掉“显示按键名”后只显示一个墨点，连键名都不进 DOM。

### 2. 激光

- 起点固定在**原来的天线尖端**（珠子局部 48,24；场景 252,188）。
- 一条细激光：辉光 3px / 亮芯 0.8px，琥珀色 #B97818，0.3 秒淡出。
- 命中后字块消失，位置炸开一圈 6 颗小点。
- 连续输入时每 150ms 打一发；同时最多保留 2 条激光，避免糊成一片。
- 第一发在字块出现约 320ms 后，给眼睛留出“看过去”的时间。

### 3. 眼睛

- 不新增瞳孔，只让原来的两颗白点整体平移：
  - 有字块：朝最老的字块，x 方向最多 3px，y 方向最多 3px。
  - 没字块：跟鼠标指针；7 秒无输入回正。
  - 眨眼/睡着/打哈欠：换成原来的闭眼弧线，不移动。
- 珠子本体不动、不转头；这是“只加动作”的边界。

- 珠子仍在右下角，92px；窗口向左上扩出一块透明区域给字块和激光。
- **平时只有珠子可点**；有字在飞时临时打开整块场景，字打完就缩回。这样不会常驻挡住桌面。
- 提醒卡出现在珠子上方，内容、按钮、10/30/60 分钟推后都不变。
- 保存的位置仍是珠子左上角；旧版 pet.x/y 不需要迁移，升级后珠子还在原地。

## 状态

| 状态 | 触发 | 表现 |
| --- | --- | --- |
| 发呆 | 无输入 | 呼吸、环、偶尔眨眼（原样） |
| 打字 | 刚敲键 | 两颗白点朝字块平移，尖端发射激光 |
| 连续击发 | 字块 ≥ 3 | 激光连发，字块排队 |
| 悬停 | 指针进入珠子 | 气泡显示下一个到点（原样） |
| 到点 | 到点/逾期 | 环变琥珀、摊卡（原样） |
| 深夜 | 22:00–08:00 | 闭眼变灰（原样）；一敲键就醒 |
| 被捏 | 按住 520ms | 压扁回弹（原样） |

## 隐私

- 只读当前按下的物理键名；不读文本、不读输入法候选、不读剪贴板。
- 字块只活在组件内存里，约 1 秒；命中即删除。
- 不写日志、不落盘、不联网；Rust 日志只记“输入跟随启动/暂停”。
- 关闭跟随、窗口隐藏、锁屏、全屏、演示模式时直接跳过。
- 设置里可关闭键名，只显示墨点。

## 技术建议（仅为设计，不改代码）

- Windows 用 GetAsyncKeyState 30ms 轮询 + GetCursorPos，不装全局钩子；键名映射后发到桌宠窗口。
- 前端用 requestAnimationFrame 推进字块/激光/墨点；没有字块时停止，空闲 0 帧。
- 动态点击区域：默认只有 96×96 珠子；effect 模式临时覆盖 300×260 场景；card/menu/hover 各自并集。
- 窗口 300×300，珠子 96×96 锚定右下；保存位置 = 珠子左上角，和旧版一致。
- 已知限制：普通权限读不到“以管理员身份运行”的窗口里的按键（Windows UIPI）。

## 验收

- 任何状态下珠子的形状/尺寸/颜色/位置与现在截图一致；逐像素对比只多字块、激光、墨点，眼睛白点最多偏移 3px。
- 10 键/秒：每个字块至少可见约 250ms，600ms 内被击中；眼睛和激光都朝向它。
- 20 键/秒：字块排队，最多 14 块；不崩溃、不丢按键。
- 全屏/锁屏：不产生事件；退出后恢复。
- 关闭键名：DOM 里无键名。
- 100% / 125% / 150% DPI：珠子位置、点击区、提醒卡不跑偏。
- 旧设置：pet.x/y 直接可用，珠子不跳位。

## 为什么不是猫/键盘

上一版画猫和键盘，形象和产品标志脱节；这次回到标志本身。桌面就是舞台，输入就是字块，天线就是激光发射器。珠子不需要长出手脚，也不需要换表情。
