# 珠子 · 皮肤与配件

> 珠子可以换衣服，但不能换掉自己。

图：[../out/pet/skins.png](../out/pet/skins.png) · 原型：[skins.html](skins.html)　·　前作：[互动方案.md](互动方案.md)

---

## 结论

1. **本体是品牌**：logo、托盘、应用图标、帮助页里的图，永远是裸珠。只有桌面上的那一颗能穿。
2. **材质 + 六个挂点**，默认裸珠，最多同时 3 件；同槽位互斥。
3. **配件不出圈**：全部落在窗口区域那个 r43 的圆里 —— 不动窗口、不动热区、不动吸附，**Rust 一行不用改**。
4. **状态优先于皮肤**：到点时本体临时变琥珀，材质让位，配件不动。
5. **不做抽卡、货币、签到**；解锁只挂在已有的数据上（捏过几次、完成过什么、几点在用）。

## 一、七个层

| 层 | z | 挂在哪 | 例子 |
| --- | --- | --- | --- |
| `back` 背 | 1 | 本体之后 | 纸翼、蝴蝶结带 |
| `ring` 环 | 2 | 原有 r25 环 | **不换**（时间语义，见互动方案） |
| `body` 材质 | 3 | r16 球面 | 青瓷 / 陶土 / 夜光 / 星尘 / 水波 / 纸糊 |
| `hair` 头 | 4 | 头冠 36 一带 | 呆毛、侧分、小辫、鹿角 |
| `antenna` 天线 | 5 | 天线杆 26–39 | 旗子、灯罩、蒲公英 |
| `orbit` 环轨 | 6 | 头上方 | 光圈、月相、小星 |
| `base` 底座 | 7 | 地面 84–88 | 苔藓、云朵 |
| `aura` 氛围 | — | 场景层（不进 96） | 萤火、雪、花瓣 |

三条硬规则：

- **中轴留给天线**：`x = 48 ± 4` 不许压东西。那根杆子和尖是它的识别物，配件只能站旁边。
- **眼睛跟着材质走**：青瓷是白点，纸糊就得是墨点，夜光是冷白。否则浅色材质上是白内障。
- **同时最多 3 件**：再多就不像珠子，像挂件架。

## 二、不出圈（整套设计的地基）

窗口的点击区域是 96 窗内缩 5px 的椭圆，即**半径 43、圆心 (48,48)**。而 `SetWindowRgn` 是**裁剪**，不是遮罩——出圈的像素不是透明，是根本不存在。

所以：

- 配件的包围盒必须 ≤ **r40**，画布就是这 96×96，不出画布。
- 省掉四件事：扩窗、重算吸附、重算热区、多显示器 DPI 的二次校正。
- 直接后果：**皮肤系统 100% 是前端的事**。
- 出圈的例子——气球、高帽、大翅膀、飘在头顶的字——不做；真要做得进 v2 谈扩窗，那是另一套位置存取和吸附逻辑。

反过来说，r40 是个很够用的圆：从圆心往外 40px，翅膀能展开到 x 17–79，呆毛能长到 y 18，苔藓能落到 y 88。

## 五、动效预算

- 同一时刻只有一层在动：光圈 20s 转一圈、呆毛 3.6s 摆 1px、纸翼跟着呼吸的同一个 transform 走。
- 深夜（22:00–08:00）：发光类降为静态；睡着时全不动。
- `prefers-reduced-motion`：全部静态。
- 不加新的 filter：夜光那圈光是半透明圆，不是 drop-shadow（桌宠窗口里 blur 很贵）。

## 六、解锁：只挂已有的数据

| 条件 | 得到 | 数据来源 |
| --- | --- | --- |
| 捏过 10 次 | 呆毛 | `pet.pinches`（已存在） |
| 连续 3 天完成过事 | 光圈 | `todos.completedAt` |
| 22 点后还在用，累计 5 次 | 夜光 | 按键时段（内存） |
| 完成第一份计划 | 纸翼 | `plans` |
| 其余 | 设置里直接可选 | — |

没有货币，没有抽卡，没有每日任务。**解锁是「它记得你」，不是「你来上班」。**

---

## 七、设置

- 抽屉「桌面珠子」分组下加一段「外观」：96 预览 + 槽位 tab（材质/头发/天线/环轨/背/底座）+ 六格网格 + 「随机一套」。
- `pet.look` 存进 settings.json，跟着 `settings-changed` 实时生效；和位置一样是设备本地的数据，不进云同步。
- 换装立即重绘，不做过渡动画（避免和呼吸抢 transform）。

## 八、落地

| 文件 | 改动 |
| --- | --- |
| `src-tauri/src/settings.rs` | `PetSettings.look: PetLook`（六字段，全 Option） |
| `src/domain/settings.ts` | 同步类型；默认全空 |
| `src/features/pet/PetLook.vue`（新） | 按槽位 v-if 渲染 `<g>`，28 个路径以内 |
| `src/features/pet/PetApp.vue` | 珠子 svg 里插 `<PetLook :look="settings.pet.look" />` |
| `src/features/pet/pet.css` | 三层动效，全部走 CSS 变量 |
| `src/features/settings/SettingsDrawer.vue` | 外观分区 + 预览 |

挂点和动作的关系（对着现在的 `pet.css`）：**头发、材质放进 `.pet-creature` 里面**，跟着盖章、缩身、呼吸一起变形；**背翼、光圈、底座放在它外面**，不跟着扁——不然 Enter 一盖章，翅膀也跟着塌就散了。

估算：材质 6 + 配件 9 + 十二套编排 ≈ 一天；设置页半天。

因为不扩窗、不碰热区，这条线和「互动 v2」的蓄力/热区可以并行做，互不冲突。

## 九、明确不做

- 不换 logo、托盘图标、应用图标、安装图。
- 不做会遮住提醒卡的配件（帽子、伞、飘带都不行）。
- 不做抽卡、货币、签到、限时活动。
- 不做扩窗到 96 以外——r40 之外的想象力留给 v2。
- 不做用户自定义上传 SVG：珠子的画面必须完全可预测，这是桌宠，不是画板。

---

## 十、验收

1. **96px 可读**：十二套缩到 96px 并排，每套都能叫出名字。
2. **不出圈**：任一组合的最大包围盒 ≤ r40；`git diff src-tauri` 为空。
3. **状态优先**：到点时本体琥珀、配件不变、提醒卡不被遮。
4. **夜色降级**：22 点后发光类变静态，睡着时全静。
5. **切换**：换装首帧 < 16ms，不闪、不跳、不重算位置。
6. **归零**：清空 look 后与现在的裸珠逐像素一致。
