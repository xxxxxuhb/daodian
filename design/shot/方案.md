# 到点 · 截图方案

> 状态：**设计稿**（2026-11）· 只定交互和边界，不改代码。
> 仓库里已有一版未提交的实现：`src-tauri/src/shot.rs`、`src/features/shot/`。主链路（冻结 → 拖选 → 标注 → 复制 / 贴图 / 保存）代码齐全；本文按「正常截图」的基线，把它还差的部分定下来。
> 目标：按下快捷键到图进剪贴板，不超过 3 秒。
> 结论先行：**不重写**。保留「全屏冻结 + 拖选 + 轻标注」，补上选区调整、放大镜、键盘流、贴图原位、临时文件清理和设置项；不把截图做成一个独立软件。

---

## 0. 一页结论

| 决策 | 选择 | 一句话理由 |
| --- | --- | --- |
| 入口 | `Ctrl+Alt+A`（可改）/ 托盘「截一张图」 | 和快速记录并列，都是全局入口 |
| 冻结 | 触发时一次截下所有屏幕，覆盖层冻结 | 拖选时画面不能还在动 |
| 选区 | 拖选 + 8 个把手 + 移动 + 放大镜 | 选完还能改，才像正常截图 |
| 标注 | 矩形 / 椭圆 / 箭头 / 画笔 / 荧光笔 / 文字 / 马赛克 | 够用，不堆 |
| 默认动作 | `Enter` 复制；`Ctrl+T` 贴图；`Ctrl+S` 保存 | 九成截图是为了贴到别处 |
| 贴图 | 原位、置顶、不进任务栏、悬停控件 | 贴图是「把这块内容钉在桌上」 |
| 退出 | Esc / 右键逐层退；再按快捷键直接退 | 不让人一层层找出口 |
| 临时文件 | 会话结束 + 启动时清空 | 截屏内容比待办更敏感 |
| 多屏 | P1 单屏内选区；P2 跨屏 | 先把单屏做对 |
| 扩展 | GIF / 长截图 / 取字（P3，独立入口） | 不挤主截图的三秒流程 |
| 不做什么 | 视频录屏 / 截图历史 / 云 / 自由套索 | 这是输入口，不是素材库 |

## 1. 定位

截图不是「到点」的第六个模块，它是**输入**：

- 群里一段排期 → 截下来，贴进备忘录；
- 一个报错窗口 → 截给同事；
- 网页上的表格 → 贴到桌面，照着填；
- 设计稿的一角 → 存成图片发群。

所以它必须：**快**、**不打开主窗口**、**不先问存哪**、**不打断正在做的事**。
它不需要：完整录屏、素材库、云相册、复杂排版。GIF / 长截图 / 取字是后加的扩展，单独入口，不挤主流程。

### 1.1 三个真实场景

| 场景 | 动作 | 目标 |
| --- | --- | --- |
| 把群里一句话记成待办 | 按快捷键 → 拖住那句话 → `Enter` → 切到待办粘贴 | 3 秒内离开截图 |
| 把报错发给同事 | 按快捷键 → 拖住报错框 → 画个箭头 → `Ctrl+C` → 去群里粘贴 | 标注不挡内容 |
| 照着设计稿填表 | 按快捷键 → 拖住设计稿 → `Ctrl+T` 贴图 → 滚轮缩到 60% | 贴图钉在原位，不挡表格 |

### 1.2 四条底线

1. 按下快捷键之前，不需要先打开「到点」。
2. 选完不需要再点一次「确认」。
3. 退出不需要找关闭按钮。
4. 退出后，全屏截图不留在磁盘上。

## 2. 「正常」的基线

对照 Windows 截图工具、Snipaste、微信截图，一个正常截图工具至少要做到下面这些。这张表同时是现状核对：

| # | 行为 | 正常的样子 | 现在（未提交实现） |
| --- | --- | --- | --- |
| 1 | 触发 | 全局快捷键 / 托盘，按下即冻 | 有 |
| 2 | 选区 | 拖完还能挪、能改大小 | **不能** |
| 3 | 精度 | 放大镜、像素尺寸、坐标 | 只有尺寸 |
| 4 | 标注 | 矩形 / 箭头 / 画笔 / 文字起步 | 有 |
| 5 | 复制 | `Enter` / 双击，复制有反馈 | 只能点按钮，无反馈 |
| 6 | 保存 | 默认目录 + 时间文件名 | 每次问，固定名 |
| 7 | 贴图 | 原位、置顶、可缩小 | **居中、进任务栏** |
| 8 | 退出 | Esc / 右键逐层退 | **一刀切** |
| 9 | 清理 | 退出即删临时图 | **留在盘上** |
| 10 | 多屏 | 不裂；能跨屏更好 | 单屏，各自为战 |
| 11 | 失败 | 说清原因，能退出 | 有文字，没出口 |
| 12 | 键盘 | 全流程不用鼠标 | 只能点 |

## 3. 范围

### P0 · 正常手感（2–3 天）

- 选区释放后仍可调整：8 个把手、拖动移动、方向键微调。
- Esc / 右键 / 再按快捷键，按层退出；**文字输入里按 Esc 只取消这段字**。
- 截图里默认不画鼠标指针。
- 工具条图标化，位置不盖住选区。
- 贴图出现在选区原来的位置，不进任务栏，关闭即删。
- 临时目录在会话结束和下次启动时清空。
- 保存文件名带时间；取消保存回到原选区，标注不丢。
- 复制成功有轻提示，再关闭；不是点完就消失。
- `Ctrl+A` 选整屏；空选区按 `Enter` 复制整屏。
- 失败时有「重试 / 退出」，不黑屏卡死。

### P1 · 精度与工具（4–5 天）

- 放大镜：8×、十字线、坐标、色值、尺寸。
- 工具补齐：椭圆、荧光笔、马赛克；线宽 2 / 4 / 6。
- 撤销 + 重做（各 50 步）。
- 双击复制、工具快捷键。
- 设置：保存位置、包含鼠标指针、贴图置顶、复制后自动保存。
- 多屏：焦点跟指针走，只有正在操作的那块屏出工具条。
- 非 Windows 显示「当前平台暂不支持」，设置里禁用，而不是点了才报错。
- 工具条宽度自适应；窄屏折成两行。

### P2 · 到点的截图（约 5 天）

- 跨屏选区（单窗口覆盖虚拟桌面）。
- 窗口 / 控件识别：悬停高亮，单击选窗口。
- 延时截图（3 / 5 秒）。
- 贴图：滚轮缩放、透明度、悬停控件、右键菜单。
- 「截图并插入当前笔记」：不进剪贴板，直接进 attachments。
- 大图传输优化：文件 / 自定义协议代替 base64。

### P3 · 扩展（可选，5–9 周）

- 取字（OCR）：3–5 天；Windows 本地识别，结果可复制 / 进笔记 / 变待办。
- 手动长截图：1–2 周；用户自己滚，自动拼接。
- GIF：1–2 周；5–15 秒、10fps、区域、无声。
- 取字进笔记 / 待办：3–5 天。
- 自动滚动：2–3 周；只对网页 / 标准滚动控件承诺。

### 明确不做

- 录屏、视频（GIF 是短动图，不是视频）。
- GIF 剪辑、字幕、音频。
- 通用应用的自动滚动（P3 只做网页）。
- 自由套索、不规则选区。
- 截图历史 / 素材库。
- 云同步、分享链接、团队空间。
- 贴图跨重启保存。

## 4. 交互

### 4.1 触发

| 入口 | 行为 |
| --- | --- |
| 全局快捷键 `Ctrl+Alt+A` | 开始截图；会话中再按一次直接退出 |
| 托盘「截一张图」 | 同上；即使设置里关了全局快捷键也能用 |
| 备忘录工具栏「截图并插入」（P2） | 截完直接进当前笔记，不覆盖剪贴板 |

触发时：

1. 并行截下所有显示器（**先截，再显示覆盖层**，所以覆盖层不会截到自己）。
2. 每块屏一个无边框、置顶、不进任务栏的覆盖窗口。
3. 焦点给**鼠标所在的那块屏**；其余屏也变暗、可拖选，但只有一块屏出工具条。
4. 覆盖层淡入 120ms；加载完成前不显示黑底。
5. 光标变成十字；屏幕中央出现提示：`拖一块区域 · 右键退出`。开始拖后提示消失。

失败时（没有显示器、GDI 失败、被安全策略挡住）：显示一张小卡片，写原因，两个按钮「重试」「退出」。不要把桌面盖死。

### 4.2 冻结层

- 全屏截图作为底层，上面盖一层 `rgba(4, 7, 11, 0.5)` 的暗层。
- 选区内部**不打暗**，透出原图；选区外打暗。
- 选区边框：1.5px `#8FD0EA`，外圈 1px 半透明白，保证亮底暗底都看得见。
- 8 个把手：8×8 白色方块，1px `#0C1F1A` 描边；选区小于 24px 时只留四角。
- 默认不把鼠标指针画进截图；设置里可打开「包含鼠标指针」。
- 覆盖层本身不进入截图；主窗口、「到点」的珠子如果本来就在桌面上，会被截进去，不特殊处理。

**状态与动作**

| 动作 | 结果 |
| --- | --- |
| 在空白处按下拖动 | 开始新选区；原有选区和标注立即清掉 |
| 拖动中 | 实时显示尺寸；松手进入编辑态 |
| 松手时小于 3px | 视为没选中，回到提示状态 |
| 拖动选区内部（移动工具） | 移动选区；标注跟着走 |
| 拖动 8 个把手 | 改大小；对角固定；`Shift` 保持比例 |
| 按住 `Space` 拖动 | 临时移动选区，不切换当前工具 |
| 方向键 / `Shift` + 方向键 | 移动 1px / 10px |
| `Ctrl+A` | 选中当前整块屏 |
| 双击选区内部（移动工具） | 复制并退出 |
| 在选区外重新拖 | 新选区；旧标注丢弃 |

**精度**

- 坐标一律按**物理像素**算；松手时吸附到物理像素，避免导出的图边缘发虚。
- 尺寸标在选区左上角上方；上方放不下就放下面；数值是物理像素：`1280 × 720`。
- 放大镜（P1）：140×140，8×，跟在光标右下 24px；贴边时翻到另一侧；显示十字线、坐标、色值。按 `M` 开关。文字输入时自动隐藏。
- 选区不能拖出屏幕；贴边时允许正好到边。

**多屏**

- P1：一次只在一块屏上选区；换到另一块屏拖选，旧选区清掉，工具条跟着到新屏。
- P2：一个覆盖整个虚拟桌面的窗口，选区可以跨屏；屏幕之间的空隙保持透明、不可选。见 §5。

### 4.4 标注

| 工具 | 快捷键 | 行为 |
| --- | --- | --- |
| 移动 / 选择 | `V` | 默认工具；拖选区、拖把手，不做标注 |
| 矩形 | `R` | 拖矩形；`Shift` 正方形 |
| 椭圆 | `O` | 拖椭圆；`Shift` 正圆 |
| 箭头 | `A` | 起点到终点；`Shift` 锁 15° |
| 画笔 | `P` | 自由线；圆头圆角 |
| 荧光笔 | `H` | 14px 宽、35% 透明，压在文字上仍看得清 |
| 文字 | `T` | 单击定位；`Enter` 确认，`Esc` 取消；单行 |
| 马赛克 | `B` | 拖矩形；12px 块；用于遮挡账号、手机号 |

- 颜色 6 个：`#E23B3B` / `#E6A317` / `#2F9E6B` / `#2F6FED` / `#111111` / `#FFFFFF`；默认红。
- 线宽 2 / 4 / 6，默认 3（荧光笔固定 14）。
- 标注只在选区内显示和导出；超出部分裁掉。
- 标注后再移动选区，标注跟着走；再改大小，标注不缩放，超出部分裁掉。
- `Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做；各 50 步。`Delete` 清空全部标注（可撤销）。
- 文字字号 18px / 600；颜色跟当前色；输入框透明、虚线描边；点击工具条或别处即提交。
- 画完保持当前工具，方便连续画；按 `V` 回到移动。
- 右键：正在画 → 取消这一笔；正在输入文字 → 取消这段文字；否则进入 §4.8 的退出层级。

### 4.5 工具条

```text
┌─────────────────────────────────────────────────────────────────────┐
│  ↖   ▭   ◯   ↗   ✎   ▤   T   ▦   │  ●   ━   │  ↶   ↷  │ 复制  📌  💾  ⋯  ✕ │
└─────────────────────────────────────────────────────────────────────┘
   30   30  30  30  30  30  30  30      30  30     30  30    60  30  30  30  30
   44px 高 · 圆角 12 · 按钮 30×30 · 图标 16 · 分隔线 1×20
```

- **出现时机**：松手出现，拖动时不出现；淡入 + 上移 4px，140ms。
- **位置**：
  1. 优先放在选区下方 10px，左对齐选区左边；
  2. 下方放不下，放上方 10px；
  3. 上下都放不下，放选区内侧底部，留 10px；
  4. 左右夹在屏幕内，距边至少 8px。
- **宽度**：约 590px；屏幕宽度不足 640 时折成两行，最大 `calc(100vw - 16px)`。
- **分组**：工具 8 个｜颜色 + 线宽｜撤销 + 重做｜复制 + 贴图 + 保存 + 更多 + 关闭。
- **主按钮**：「复制」是实心浅色底、深色字；其余图标按钮透明，悬停才亮。
- **更多**：最右侧「⋯」，菜单里放「录 GIF / 长截图 / 取字」（P3）；主工具条不为三个扩展加按钮。
- **提示**：悬停 600ms 出 tooltip，写名称 + 快捷键（如「矩形 R」）。
- **状态**：保存中按钮禁用，保存按钮转圈；出错时工具条下方一行红字，不遮挡选区。
- **绝不进入截图**：工具条是覆盖层 DOM，导出时只取原图 + 标注。

### 4.6 动作

#### 复制（默认）

- 入口：`Enter` / `Ctrl+C` / 双击选区 / 点「复制」。
- 把选区 + 标注合成 PNG 写进剪贴板。
- 成功：工具条上方浮一个 `已复制 · 1280 × 720` 的小胶囊，700ms 后连同覆盖层一起关闭。
- 失败：覆盖层保留，工具条下方显示原因（剪贴板被占用等），可重试。

#### 保存

- 入口：`Ctrl+S` / 点「保存」。
- 默认目录：`图片\到点截图\`（设置里可改）；不存在时创建。
- 默认文件名：`到点截图-20261123-144512.png`；重名追加 `-2`。
- 打开系统保存对话框前，先把覆盖层藏起来（否则全屏置顶层会盖住对话框）；取消后原样恢复，选区和标注不丢。
- 保存成功即关闭，不弹「已保存到…」；设置里可开「复制后自动保存」。
- 失败（磁盘满、无权限）：恢复覆盖层，显示原因。

#### 贴图

- 入口：`Ctrl+T` / `F3` / 点「贴图」。
- 把选区 + 标注变成一张置顶的小窗，**放在选区原来的位置**，尺寸与选区一致；超出屏幕时夹回工作区，留 8px。
- 覆盖层关闭，贴图获得焦点（这样 `Esc` 能关它）。
- 贴图细节见 §4.7。

#### 取消

- `Esc` / 右键（按 §4.8 层级）/ 再按一次全局快捷键。
- 不确认、不挽留；临时文件立即删除。

### 4.7 贴图

```text
┌──────────────────────────────┐
│                    [⧉] [↓] [✕]│  ← 悬停才出现
│                              │
│        截图内容 100%          │
│                              │
└──────────────────────────────┘
  原位 · 置顶 · 不进任务栏 · 拖动移动
```

| 项 | 规则 |
| --- | --- |
| 窗口 | 无边框、置顶（可在设置关）、不进任务栏 / Alt-Tab、可拖动 |
| 位置 | 选区左上角；夹在当前显示器工作区内，留 8px |
| 尺寸 | 与选区一致；锁比例；最小 24×24；超过工作区 70% 时等比缩到 70% |
| 缩放 | 滚轮 25%–400%，每档 10%；`0` 回到 100%；缩放围绕窗口中心 |
| 透明度 | `Ctrl` + 滚轮 20%–100%，每档 10%；`0` 回到 100%（P2） |
| 控件 | 右上角 3 个 28px 按钮：复制 / 另存为 / 关闭；悬停显示，移开 1.2s 消失 |
| 拖动 | 图片任意位置拖动；控件和按钮不触发拖动 |
| 键盘 | 聚焦时 `Esc` 关闭，`Ctrl+C` 复制，`0` 复位 |
| 上限 | 同时 12 张；超出提示「先关掉几张」 |
| 生命周期 | 关闭即删临时文件；退出「到点」全部关闭并清理；不跨重启恢复 |
| 外观 | 1px 内描边 + 系统阴影；不圆角，避免裁掉截图内容 |

### 4.8 退出层级

| 当时在做什么 | `Esc` | 右键 | 再按全局快捷键 |
| --- | --- | --- | --- |

## 5. 多屏与 DPI

### 5.1 P1：一块屏一个覆盖层

- 每块显示器一个无边框窗口，位置和尺寸用物理像素。
- 焦点跟鼠标走；在一号屏拖选时，二号屏只变暗，不出工具条。
- 一次只保留一个选区；换屏重新拖选时，旧选区清掉。
- 工具条的键盘操作只作用于当前活动屏。
- 优点：实现简单，DPI 各算各的；缺点：选区不能跨屏。

### 5.2 P2：跨屏

- 计算虚拟桌面外接矩形：`x = min(left)`、`y = min(top)`、`w = max(right) - x`、`h = max(bottom) - y`。
- 一个覆盖整个矩形的窗口；每块屏的截图按各自偏移拼进去，屏幕之间的空隙透明、不可选。
- 大图用文件 / 自定义协议交给 WebView，不走 base64。
- 风险：一个窗口只有一个 DPI 比例，混合缩放（125% + 150%）会错位；需要按物理像素定位并关闭 WebView 的自动缩放，逐台机器验证。
- 结论：P1 不做；如果跨屏是高频需求，再单独立项，不要为了它把单屏的稳定性拖下水。

### 5.3 DPI 规则

- 内部一律物理像素；前端用 `devicePixelRatio` 换算。
- 松手吸附到物理像素；尺寸显示物理像素；导出按物理像素。
- 必须测：100%、125%、150%、200%；125% + 150% 混合；副屏在左侧（负坐标）；竖屏；笔记本 + 外接屏。
- 已知限制：独占全屏的游戏、DRM 保护内容、部分 HDR 画面，GDI 截出来可能是黑的。失败时给一句人话，不要静默黑屏。

## 8. 技术建议（仅为设计，不改代码）

### 8.1 不重写

现有架构是对的：Rust 负责截屏、窗口、剪贴板、文件；Vue 负责冻结层、选区、标注。问题集中在会话状态、退出路由、清理和工具条，不在语言或框架。

### 8.2 截图

- 每块屏并行截，不要串行等；截完统一写文件。
- 默认不画光标；「包含鼠标指针」作为可选。
- 用 `shots/live/<session>/<screen>.png`，会话 ID 用时间戳或随机串，避免并发覆盖。
- 全屏图不要走 base64：Rust 返回路径，前端用 `convertFileSrc` + asset scope 加载；scope 不方便时注册 `shot://` 自定义协议。base64 只做兜底。
- 3×4K 的 PNG 大约 15–25MB；base64 会膨胀 1/3，还会在 IPC 里多一份内存。目标是会话结束内存回到基线 ±50MB。

### 8.3 会话状态

Rust 持有一份 `Session`，前端每个覆盖层是它的视图：

```rust
struct Session {
    id: String,
    screens: Vec<ScreenInfo>, // index, path, x, y, w, h, scale
    phase: Phase,             // Select | Edit | Saving
    modal: bool,              // 系统保存对话框是否打开
}
```

命令草案：

```text
shot_begin() -> Vec<ScreenInfo>
shot_escape()                 // 请求前端按层级处理
shot_copy(png) -> ()
shot_save(png) -> Option<String>
shot_pin(png, rect) -> usize
shot_pin_close(id)
shot_cancel()
```

### 8.4 Esc 路由（P0 的关键）

现在：全局键盘钩子 → `handle_escape` → 立刻 `force_hide` + `request_cancel`。它不知道前端在输入文字，也不知道保存对话框开着。

改成：

1. 钩子只负责把 `shot://escape` 事件发给**活动覆盖层**，不直接隐藏。
2. 前端用一个纯函数 reducer 处理层级：`text → drag → selection → exit`；需要退出时再调 `shot_cancel`。
3. 前端处理完回一个 `shot_escape_ack`；150ms 没回（WebView 卡住），Rust 再兜底关闭。
4. 保存对话框打开时 `modal = true`，钩子不拦 Esc，让系统对话框自己处理。
5. Esc 分支只在截图会话 / 贴图存在时生效；Alt+Space 兜底分支不受影响。若以后去掉兜底，整个钩子可以按会话启停，减少被杀软盯上的概率。

### 8.5 焦点与多屏

- `shot_begin` 时找鼠标所在显示器，对该覆盖层 `set_focus`。
- 任意覆盖层 `pointerdown` 时先 `set_focus`，保证键盘事件落在正确窗口。
- P1 一次只允许一个活动屏；其他屏收到事件直接忽略。

### 8.6 临时文件与清理

- 启动时删 `shots/live`、`shots/gif`、`shots/long`、`shots/clipboard`、`shots/pins` 下所有内容；会话结束时删本会话目录；贴图关闭时删对应文件。
- 清理失败只记日志，不弹窗。
- 退出应用时关闭所有贴图窗口，再删目录。
- 不要把截图放进 `attachments`；只有 P2「插入笔记」才走笔记附件。

### 8.7 贴图

- `shot_pin` 增加 `rect: { x, y, w, h }`，Rust 用它设位置和大小；不要只看 PNG。
- `skip_taskbar(true)`；Windows 上用 tool window 样式去掉 Alt-Tab 项。
- 锁比例：`set_aspect_ratio(w / h)`；最小 24×24。
- 悬停控件和滚轮缩放在前端做，窗口大小变化通过命令回 Rust。
- 关闭、崩溃、退出三条路径都要删文件。

### 8.8 保存

- 默认文件名带秒；重名加序号。
- 对话框期间隐藏覆盖层；取消恢复，成功关闭。
- 默认目录从设置读；不存在时创建；创建失败退回数据目录下的 `shots`。
- 格式先只做 PNG；JPG 作为 P2（质量 90，透明区域填白）。

### 8.9 性能预算

| 场景 | 预算 |
| --- | --- |
| 1080p 按下 → 冻结层可见 | ≤ 200ms |
| 3×4K 按下 → 冻结层可见 | ≤ 400ms |
| 松手 → 工具条出现 | ≤ 1 帧 + 140ms 动画 |
| 复制 1280×720 → 剪贴板 | ≤ 120ms |
| 保存 4K PNG | ≤ 800ms（不含用户选路径） |
| 取字 1280×720 | ≤ 800ms |
| 长截图拼 5 屏 | ≤ 1.5s（不含用户滚动） |
| GIF 5 秒 / 720px 编码 | ≤ 3s；录制内存 ≤ 150MB |
| 空闲内存 | 会话结束回到基线 ±50MB |

### 8.10 测试

- `boxFromPoints` / `insideBox` / 把手命中 / 吸附取整。
- Esc reducer：文字 → 拖拽 → 选区 → 退出，四种状态各一条。
- 文件名生成、重名追加、目录创建失败回退。
- 清理：启动清空、会话结束清空、贴图关闭删除。
- 多屏坐标映射：负坐标、竖屏、混合 DPI。
- 扩展：GIF 帧数 / 体积、长截图重叠匹配、OCR 语言包缺失。
- 手工验收：§11。

## 9. 数据与隐私

- 全屏截图只在 `shots/live/<session>` 里短暂存在；会话结束、下次启动都删。
- 贴图文件只在 `shots/pins`；关闭、退出、崩溃后由启动清理兜底。
- 不把截图内容写日志；日志最多记「会话开始 / 结束 / 失败原因」。
- 不联网、不上传；「到点」没有截图云同步。取字用 Windows 本地 OCR，图片和文字都不出本机。
- GIF 帧、长截图帧放在 `shots/gif/<session>`、`shots/long/<session>`，完成 / 取消 / 退出即删。
- 复制只写剪贴板；保存只写用户选的目录。GIF 复制的是临时文件，保留到下一次复制或下次启动清理；复制后不要立刻删，否则粘贴找不到源文件。
- 截屏可能包含密码、聊天、工资单；默认不保留历史。以后若做历史，必须显式开启、默认 7 天、可一键清空。
- DRM / 独占全屏截出来是黑的，这是系统限制；提示用户，不要假装成功。

## 11. 验收

1. 1080p 按下快捷键到冻结层可见 ≤ 200ms；3×4K ≤ 400ms。
2. 拖选后：8 个把手都能改大小；拖动内部能移动；方向键 1px / 10px；`Shift` 正方形；尺寸显示与导出像素一致。
3. 100% / 125% / 150% / 200% 以及混合 DPI：选区不偏、不虚、尺寸正确。
4. 文字输入按 `Esc` 只取消文字；再按 `Esc` 取消选区；再按退出。右键同样逐层。
5. `Enter` / `Ctrl+C` / 双击都能复制；粘贴到画图、微信、备忘录，颜色和尺寸正确；有 700ms 提示。
6. `Ctrl+S` 默认目录 + 时间文件名；取消保存回到原选区，标注不丢；重名不覆盖。
7. 贴图出现在选区原位、置顶、不进任务栏；拖动、滚轮缩放、`Esc` 关闭；12 张上限有提示。
8. 退出、崩溃后重新启动：`shots/live`、`shots/gif`、`shots/long`、`shots/clipboard`、`shots/pins` 为空；没有残留窗口。
9. 多屏（含负坐标、竖屏）每块屏都能截；P1 单屏选区不裂；P2 跨屏时选区连续。
10. 独占全屏 / DRM：给出可读的失败提示，能退出，不黑屏卡死。
11. 快捷键冲突、关闭、非 Windows：状态清楚；托盘入口仍可用。
12. 全程键盘可完成一次截图：快捷键 → 方向键选区 → `R` 矩形 → `Enter` 复制。
13. 工具条在四角选区、小选区、窄屏下都不盖住选区、不出屏。
14. 3×4K 会话结束内存回到基线 ±50MB；保存 4K PNG ≤ 800ms。
15. 日志不出现截图内容，只出现会话事件和错误原因。
16. GIF：5 秒、720px、10fps，预览循环；保存的 GIF 能被微信 / 飞书当文件发送；体积 ≤10MB；取消后无临时文件。
17. 长截图：浏览器 3–5 屏手动滚动，接缝不明显；吸顶栏有已知限制说明；到 20 屏 / 20000px 停止；取消清理。
18. 取字：中英文 12px 截图可识别、可编辑、可复制；缺语言包有提示；断网可用。
19. 扩展入口不破坏主流程：不点「⋯」时，截图仍然 3 秒复制；主工具条宽度不显著增加。
20. 扩展的临时帧 / 长图在完成 / 取消 / 退出后清理；取字文本不写日志、不联网；GIF 复制文件按剪贴板规则保留到下次复制 / 启动。

## 13. 扩展能力：GIF、长截图、取字

> 这三个都不进主截图的三秒流程。主流程仍是「拖一块 → 复制」；扩展从工具条最右侧的「⋯」或托盘进入，做完回桌面。
> 顺序：先取字（3–5 天），再手动长截图（1–2 周），最后 GIF（1–2 周）。自动滚动和「取字进待办」再往后。

### 13.1 入口与边界

| 入口 | 行为 |
| --- | --- |
| 工具条「⋯」 | 录 GIF / 长截图 / 取字 |
| 托盘右键 | 截一张图 / 录 GIF / 长截图 / 取字 |
| 覆盖层快捷键 | `G` / `L` / `Ctrl+Shift+O` |

- 三个入口都先要有选区；没有选区时提示「先拖一块区域」。
- 进入扩展后，主工具条收起，换成该模式的浮动控制条；`Esc` 逐层：录制中停止并预览 → 预览 / 面板关闭回到选区 → 再按一次退出截图。
- 扩展结果先预览，不自动覆盖剪贴板。
- 主工具条只多一个「⋯」，不为三个扩展加大按钮。
- 三个扩展共用现有的临时目录清理；退出后不留帧、不留 GIF、不留长图。

**总览**

| 能力 | 输入 | 输出 | 默认上限 | 入口 |
| --- | --- | --- | --- | --- |
| 录 GIF | 选区 | `.gif` | 15 秒 / 720px / 10MB | ⋯ / 托盘 / `G` |
| 长截图 | 选区 + 手动滚动 | 一张长 `.png` | 20 屏 / 20000px | ⋯ / 托盘 / `L` |
| 取字 | 选区 | 可编辑文本 | 10000 字 | ⋯ / 托盘 / `Ctrl+Shift+O` |

### 13.2 录 GIF

**定位**：5–15 秒的操作演示，不是录屏。区域、无声、10fps，最大 720px 宽。

**流程**

1. 选区 →「⋯」→ 录 GIF。
2. 3 秒倒计时；录制区域外框变琥珀色，右上角计时胶囊。
3. 录制中：区域本身不挡鼠标，用户可以正常操作；控制条浮在区域外，只有「停止」可点。
4. 停止：点停止 / 按 `Esc` / 到 15 秒。
5. 预览：循环播放、帧数、尺寸、文件大小；按钮「复制文件 / 保存 / 重录 / 关闭」。
6. 默认不自动保存；保存到 `图片\到点截图\GIF\`，文件名带时间。「复制文件」写到 `shots/clipboard/<id>.gif`，下次复制或下次启动清理。

**参数**

| 项 | 默认 |
| --- | --- |
| 帧率 | 10fps（可选 15） |
| 最长 | 15 秒 |
| 最大宽 | 720px，超过等比缩 |
| 颜色 | 256 色，开抖动 |
| 音频 | 无 |
| 体积上限 | 10MB，超过提示缩短 / 降帧 |
| 剪贴板 | 复制的是**文件**（CF_HDROP），不是动图位图 |
| 剪贴板文件 | `shots/clipboard/<id>.gif`，下次复制 / 启动清理 |

**技术**

- 不能用现在的 GDI 逐帧抓：CPU 高、易掉帧。用 Windows Graphics Capture 或 DXGI。
- 帧边录边缩到目标宽，环形缓冲；停止后编码 GIF，控制内存 < 150MB。
- 编码放工作线程；有进度、可取消；临时文件退出即删。
- 录制边框窗口要鼠标穿透（`set_ignore_cursor_events`），控制条单独一个小窗；否则录的时候点不到内容。
- Windows 剪贴板没有通用的「动图」格式；复制文件最兼容。粘到微信 / 飞书是文件，粘到浏览器 / 编辑器可能不认。
- 已知限制：HDR / DRM / 独占全屏可能黑；大区域 + 15fps 会掉帧。

### 13.3 长截图 / 滚动截图

> 滚动截图是动作，长截图是结果；这里当成一个能力：先手动滚动，再自动滚动。

**先做「手动滚动 + 自动拼接」，再做「自动滚动」。** 前者在所有应用里都能用，后者只对网页 / 标准滚动控件可靠。

**流程（手动，P3）**

1. 选区 →「⋯」→ 长截图。
2. 抓第一屏；控制条显示「已拼 1 屏 · 1080px」。
3. 用户自己滚动；停下约 300ms 自动抓下一屏；也可以按 `Space` 手动抓。
4. 每屏做重叠匹配；对不上就提示「这一屏没对上，往回滚一点再试」。
5. 控制条：撤销上一屏 / 完成 / 取消；最多 20 屏或 20000px 高。
6. 预览长图；复制 / 保存；关闭。

**自动滚动（P3.5，可选）**

- 对鼠标下的窗口发滚轮事件（SendInput），每滚一屏抓一帧；连续两帧无变化视为到底。
- 只承诺浏览器 / 网页和标准滚动控件；游戏、虚拟列表、横向滚动不承诺。
- 自动滚动时用户不要动鼠标；提供「停止」。

**拼接规则**

- 重叠 15%–30%；上一屏底部与下一屏顶部做灰度模板匹配（SAD / NCC）。
- 分数低于阈值就丢弃这一帧，不硬拼。
- 吸顶栏 / 固定底栏会重复：先裁掉匹配区域里的重复条；裁不掉的，预览里提供「裁掉顶部 / 底部 N px」手动修正（P3.5）。
- 宽度不变；高度上限 20000px，超过停止并提示。

**输出**

- PNG；默认文件名 `到点长截图-YYYYMMDD-HHmmss.png`；目录同截图。
- 可选「复制」；大图剪贴板可能慢，给进度。
- 临时帧在完成 / 取消 / 退出后删除。

**技术**

- 抓帧用现有静态截图管线即可；关键在拼接，不在采集。
- 用 `image` crate 做灰度降采样 + 滑动窗口匹配；不引 OpenCV。
- 手动模式的稳定性来自「用户控制滚动」，不是算法。
- 已知限制：懒加载、动画、吸顶栏、横向滚动、固定侧栏。

### 13.4 取字 / OCR

> 「取字」是用户看到的入口名；「OCR」是底层引擎。不做两套，避免两个按钮干同一件事。

**定位**：把截图里的字变成可复制文本；不做排版还原，不做翻译。

**流程**

1. 选区 →「⋯」→ 取字（`Ctrl+Shift+O`）。
2. 本地 OCR，200–800ms；结果面板出现在选区右侧，不挡选区。
3. 结果可编辑；按钮：复制 / 插入当前笔记 / 变成待办 / 关闭。
4. 识别失败 / 语言包缺失：面板里写原因 +「打开 Windows 语言设置」。

**规则**

- 引擎：`Windows.Media.Ocr`（系统自带，本地，不上传）。
- 语言：跟随系统，优先简体中文 + 英文；缺语言包提示安装。
- 预处理：2× 放大、灰度、暗底反色；保留换行；去首尾空白；最多 10000 字。
- 准确率：12px 以上、正体、清晰截图；手写 / 艺术字 / 低分辨率不承诺。
- 隐私：文字只在内存；不写日志、不联网；关闭面板即清空。
- 「插入当前笔记」：走笔记的文本插入，不建图片附件。
- 「变成待办」：第一行做标题，其余进备注；时间解析交给 DeepSeek（可选，没有 Key 就建无时间待办）。

**技术**

- `windows` crate 调 WinRT：`OcrEngine::TryCreateFromUserProfileLanguages`、`RecognizeAsync`。
- 选区图转 `SoftwareBitmap`（BGRA8）；异步等待；结果按行拼回。
- 语言包检测：`OcrEngine::AvailableRecognizerLanguages`；没有中文就回退英文并提示。
- 不做云端 OCR；不引 Tesseract / PaddleOCR（体积 / 维护）。

### 13.5 顺序与工期

| 顺序 | 能力 | 工期 | 依赖 | 建议 |
| --- | --- | --- | --- | --- |
| 1 | 取字（Windows OCR） | 3–5 天 | 现有选区 + 图像 | 先做，价值最高 |
| 2 | 手动长截图 | 1–2 周 | 选区 + 拼接 | 第二做 |
| 3 | GIF | 1–2 周 | WGC / DXGI + 编码 | 有人明确要再做 |
| 4 | 取字进笔记 / 待办 | 3–5 天 | 笔记 / 待办 API | 跟着取字 |
| 5 | 自动滚动 | 2–3 周 | 手动长截图 | 只对网页承诺 |
| — | 视频录制 / 音频 | 不做 | — | 另一条产品线 |

### 13.6 验收

- GIF：5 秒 720px 10fps，预览循环；保存的 GIF 能被微信 / 飞书当文件发送；体积 ≤10MB；取消后无临时文件。
- 长截图：浏览器 3–5 屏手动滚动，接缝不明显；吸顶栏有已知限制说明；到 20 屏 / 20000px 停止；取消清理。
- 取字：中英文 12px 截图可识别、可编辑、可复制；缺语言包有提示；断网可用。
- 扩展不改变主流程：不点「⋯」时，截图仍然 3 秒复制。

### 13.7 风险

| 风险 | 对策 |
| --- | --- |
| GIF 体积 / CPU | 限 15 秒、720px、10fps；编码在工作线程；超过 10MB 提示 |
| 长截图接缝 / 吸顶栏 | 手动滚动 + 阈值丢弃；预览里给手动裁切；不承诺 100% |
| OCR 语言包 / 准确率 | 检测语言包；缺了提示安装；12px 以下不承诺 |
| 剪贴板不认动图 | 复制文件而不是位图；预览里说明 |
| 扩展维护成本 | 三个能力分三阶段；不在 P0–P2 混做 |

## 14. 备选方案

| 方案 | 做法 | 优点 | 为什么不选 |
| --- | --- | --- | --- |
| B1 调系统截图 | `ms-screenclip:` 唤起 Windows 截图工具 | 零维护、用户熟悉、自带 OCR | 没有原位贴图、没有自定义标注、无法和备忘录联动；只在 Windows |
| B2 换 `xcap` 截图库 | 用跨平台 crate 替 GDI | 以后上 macOS / Linux 省事 | 现在只支持 Windows；GDI 够用，换库不是 P0 |
| B3 网页 `getDisplayMedia` | WebView 里申请屏幕流 | 不用 Rust | 需要用户授权，延迟高，不能冻结，不适合截图工具 |
| B4 GIF 用 ffmpeg | 录屏后调用 ffmpeg 转 GIF | 编码成熟 | 安装包大、许可、进程管理；先试 WGC + `gif` crate |
| B5 浏览器全页截图 | 调 Edge / Chrome 的 full-page 截图 | 网页长图简单 | 只能网页，不能覆盖桌面 / 应用 |
| B6 云端 OCR | 上传图片到 OCR 服务 | 准确率高、跨语言 | 截图敏感、要联网；违背本地优先 |
| B7 本地 Tesseract / PaddleOCR | 打包 OCR 模型 | 不依赖系统 | 体积大、中文模型重、维护高；先用 Windows OCR |

结论：主截图保留 A；扩展按 §13 的顺序：取字优先 Windows OCR，长截图先手动拼接，GIF 用 WGC + `gif` crate；不引入 ffmpeg / OpenCV / 云端 OCR。

## 15. 和现有功能的关系

- **快速记录**：两个全局快捷键并列；设置里互相查重，冲突时明确说是和谁冲突。截图会话中按 `Alt+Space` 不应弹快速记录（P1 加互斥）。
- **托盘**：菜单加「截一张图」；P3 再加「录 GIF / 长截图 / 取字」子菜单。即使设置里关了全局快捷键，托盘仍可用。
- **备忘录**：现在截图后复制、在笔记里粘贴即可；P2 加「截图并插入」；P3 取字结果可以直接插入当前笔记。
- **桌面珠子**：珠子是桌面的一部分，会被截进去；不特殊隐藏。珠子挡住选区时，用户自己拖开或隐藏。
- **备份 / 导出**：截图、GIF、长截图都不进 `store.json`、不进备份；保存的文件在用户选的目录；临时图不备份。
- **扩展**：GIF / 长截图 / 取字从「⋯」和托盘进入；结果先预览再保存；取字文本只在内存，关闭即清。
- **主题**：覆盖层固定深色，不跟随青瓷 / 夜航；设置抽屉跟随主题。

## 17. 一句话

**截图是「到点」的输入口：按下、拖住、复制，三秒结束；选错了能改，退错了能回，关掉了不留痕。GIF / 长截图 / 取字从「⋯」进，做完回桌面，不挤主流程。**
