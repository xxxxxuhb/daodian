# 版本历史 · 交互设计

> 配套原型：design/history/ui.html（可点，右下角切屏与主题）
> 技术方案：design/history/方案.md

## 1. 三个入口

| 入口 | 位置 | 用途 |
| --- | --- | --- |
| 历史面板 | 编辑抽屉顶部「历史」 | 针对当前这一条，最常用 |
| 条目菜单 | 列表卡片 ⋯ → 查看历史 | 不打开编辑器也能看 |
| 最近变更 | 侧栏 / 设置 | 全局回溯：昨天改过哪条 |

三个入口都落到同一个面板，只是预选对象不同。

## 2. 版本列表

~~~text
历史   4 个版本                    ×
──────────────────────────────────
● 今天 10:32  [当前]
  改时间 10/28 17:30 → 今天 17:30
○ 今天 09:15  [编辑]
  改标题 1.2 提测 → 1.2 版本提测清单
○ 昨天 18:40  [阶段]
  完成阶段「提测」
○ 10/28 14:02 [新建]
  创建了这份计划
──────────────────────────────────
[ 与当前版本对比 ]
~~~

规则：

- 倒序，默认选中「当前」，不可恢复自己；
- 每条一行摘要，说清改了什么，不写「编辑」了事；
- 变化的旧值划掉、新值绿字，扫一眼就知道差异；
- hover 才出现「查看」，避免满屏按钮；
- 单击整行 = 进入预览。

## 3. 预览态

进入后整页变成只读视图，顶部一条琥珀色提示：

~~~text
正在看 10/28 14:02 的版本        [回到当前]
~~~

内容区下方固定一块「相对当前版本」：列出这一版和现在的差异（标题、时间、阶段数），让人知道恢复会失去什么。

底部操作条：

~~~text
只读预览，不会改到当前内容      [返回] [恢复到这个版本]
~~~

- 预览不提供任何编辑入口，避免「在历史里改完发现没保存」；
- 「回到当前」和「返回」都只是退出预览，不弹确认。

## 4. 恢复确认

点「恢复到这个版本」弹确认框，正文列出三件会发生的事：

1. 当前内容会先存成一个版本，点错了还能退回来；
2. 更新时间会记成现在，云同步会推一次；
3. 阶段完成记录也会一起回到那一刻。

- 默认焦点在「取消」，Esc 关闭；
- 按钮文案是「恢复」，不是「确定」——说清动作。

## 5. 恢复之后

底部轻提示，停留 8 秒：

~~~text
已恢复到 10/28 14:02 的版本            [撤销]
~~~

- 点「撤销」= 再恢复一次「恢复前」那一版，不需要用户自己去列表里找；
- 提示消失后仍可从历史里手动回滚。

## 6. 最近变更（全局）

- 按天分组（今天 / 昨天 / 10/28），倒序；
- 每行：类型标记（待 / 计 / 记）+ 对象名 + 时间 + 「查看」；
- 顶部四个筛选：全部 / 待办 / 计划 / 笔记；
- 点「查看」= 直接打开该条的历史面板，并选中那次变更。

## 7. 回收站

删除的条目进回收站，历史保留 90 天。

| 操作 | 行为 |
| --- | --- |
| 恢复 | 条目回到原列表，id 不变，历史接续 |
| 永久删除 | 二次确认，连同历史一起清掉 |
| 超期 | 90 天后自动清，不提示 |

列表显示「3 天前删」，让人有紧迫感但不打扰。

## 8. 边缘状态

| 情况 | 表现 |
| --- | --- |
| 刚新建 | 历史只有一条「新建」，仍可打开，显示为单条 |
| 历史被清理过 | 顶部一行灰字：更早的版本已清理 |
| 备忘录附件已清理 | 预览里显示占位块，附一句「这张图已被清理」 |
| 云同步进行中恢复 | 允许；恢复后同步会推一次，状态栏照常转 |

## 9. 键盘

| 键 | 作用 |
| --- | --- |
| Esc | 关闭预览 / 关闭确认框 |
| ← → | 在预览里切上一版 / 下一版 |
| Enter | 预览里聚焦「恢复」按钮（需 Tab 到） |

## 10. 动效

| 动作 | 时长 | 说明 |
| --- | --- | --- |
| 面板滑入 | 180ms | 从右侧推入，抽屉同时压暗 |
| 预览切换 | 120ms | 内容淡入，不整页重绘 |
| 恢复确认 | 140ms | 遮罩淡入 + 对话框 0.98 → 1 缩放 |
| 恢复成功提示 | 200ms | 从底部滑入，8 秒后淡出 |

## 11. 状态机

~~~text
列表 --点击版本--> 预览 --恢复--> 确认 --确认--> 列表（+ 撤销提示）
  ^                  |                 |
  |                  └--返回/Esc-------┘
  └------------------取消--------------
~~~

## 12. 设计要求汇总

- **不用弹窗做浏览**：列表在侧栏，不打断编辑；
- **必须能看见差异**：只说「改过」没用，要写清从什么改到什么；
- **恢复前给后果清单**：三条，不多不少；
- **恢复后给撤销**：一次确认不够，要留后路；
- **预览只读**：历史里不能编辑，避免状态打架。
